Sync across devices

Your favorites, reading status and bookmarks are saved on the device you are using. To see them on your phone and your computer, connect them both below.

Status

Connect GitHub (automatic)

  1. Open this GitHub page and sign in.
  2. Leave only gist ticked, set Expiration to No expiration, and press Generate token.
  3. Copy the token and paste it here. Do the same on each device.

The token stays in this browser. Your list is kept in a private gist on your own GitHub account.
